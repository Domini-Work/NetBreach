Lines 128-156: `calc_blast_radius()` function implements the Breadth-First Search (BFS) algorithm to determine the potential reach from a compromised node. Lines 158-208: `calc_least_resistance()` function implements Dijkstra's algorithm to find the lowest-cost (easiest) attack path between two specific nodes. It maintains an array of shortest known distances and a parent tracking array to reconstruct the optimal path. If a path is found, it calculates the total cost and prints the sequence of compromised assets from start to target.
Lines 210-244: `main()` function serves as the program's entry point. It initializes the graph structure and enters an infinite loop presenting a Command Line Interface (CLI) menu. It uses a `switch` statement to call the appropriate graph operation based on user input, ensuring the looping menu requirement is met until the user selects the "Exit" option.
